## 2. Run the free offline exact-row utility

**Current free release: v9 (November 6, 2026).** Original Cark/OPS Python standard-library tool, with exact-row deduplication and a guarded receipt-failure rollback. It is **not** the separately paused $59 service, a customer-delivered result or a general spreadsheet cleanup tool.

**[Download current CSV Dedupe v9 (ZIP)](https://media.base44.com/files/public/6a89094776dbb07b37c5ae96/fb18deab5_CARK_Offline_Exact_CSV_Dedupe_v9_FREE_20261106.zip)** — ZIP SHA-256 `d1da0d837e54aac9b6b71bfdf35936f9a83b330497c52aa33fc234d546791046`. Inside: exact [v9 Python source](samples/csv-qa/offline-exact-v9/conservative_csv_dedupe.py), [17 inherited tests](samples/csv-qa/offline-exact-v9/test_conservative_csv_dedupe.py), [3 rollback tests](samples/csv-qa/offline-exact-v9/test_windows_rollback_v9.py), and [current instructions](samples/csv-qa/offline-exact-v9/README.md). Public original source SHA-256 `a2c48d6543e312b62c5cb6c92248019b497f21c3c6059e222ee92cb7792fb792`.

**Acceptance and boundaries:** Native Windows 11 NTFS/Python 3.13.15: 20/20 synthetic unit tests passed, including deliberately failed receipt publication, no-overwrite and source preservation. Linux also passed 20/20 tests. No customer file, paid job or real-world business-data correctness was established. **Not tested/approved:** Windows SMB shares, Dropbox/OneDrive-synchronized output, antivirus interference, sudden power loss, adversarial races or sensitive data. Run **only on copies of non-sensitive UTF-8 CSV** in a private **local, nonsynchronized folder**. Python 3.9+ and no cloud, additional package or account required.

Run `python conservative_csv_dedupe.py yourfile.csv` after extracting the ZIP. It creates new `yourfile.deduped.csv` and `yourfile.dedupe-receipt.json` files alongside the input, preserving the original, refusing existing output and reporting row counts/hashes. Maximum input is **1,000,000 bytes and 10,000 data rows** with unique nonblank headers; it does not normalize whitespace, infer business keys, clean XLSX or approve accounting decisions. Missing receipt, failure, or unmatched output means stop and investigate; never overwrite, blindly retry or automatically delete somebody else's file.

**CSV formula safety:** The tool preserves formula-looking text. A cell beginning with `=`, `+`, `-` or `@` can be interpreted as a formula by spreadsheet software. Do **not** open untrusted CSV output in applications that evaluate it without an appropriate safe inspection process.
